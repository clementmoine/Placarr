# Naruto Carddass / CACG Bandai — recherche sources

> Statut : **recherche only** (2026-08-12). Pas de provider Placarr, pas de pack
> foil. Besoin utilisateur : **Naruto Carddass Bandai** / **Naruto Cartes à jouer
> et à collectionner** (ère ~2002–2008 FR / JP Carddass ; pas le TCG Bandai 2027).
>
> Contrat produit (idem One Piece / Pokémon sans Live) :
> - **Catalogue** (éditions, printKey, images, finitions) = obligatoire.
> - **Rendu foil** = seulement s’il existe des **masks / plaques** réelles.
> - Sans mask : tag foil / holo sur l’exemplaire OK, **face plate**.

## 1. FR — ce que le collectionneur appelle « Carddass / CACG »

Édition européenne Bandai (« Naruto Cartes à jouer » au dos ; exemplaires **Made in Belgium** attestés, copyright Kishimoto / Bandai, ex. 2007).

### Numérotation FR (vérifiée Manga-News + phys.)

| Préfixe | Type FR | Exemple |
|---------|---------|---------|

### 1bis. Ce qu’on avait zappé — hors checklist « Série 1–5 booster »

#### Promos FR (tournois Bandai)

Même **numéro** `NI/TE/TA` que la carte retail, mais **variante promo** :

- En bas de carte : **1 / 2 / 3 shuriken** à la place de la référence imprimée standard.
- Plus de shuriken = plus rare (récompenses tournoi / Japan Expo / ranking, tirages parfois minuscules).
- Premières vagues = surtout **rééditions** de cartes existantes (pas forcément art/effet exclusifs) — communauté 2007 : [narutoccgfrance — promos](https://narutoccgfrance.1fr1.net/t544-les-cartes-promotionnelles).
- Exemples cités : TE-01 Kunai / Shuriken, NI-34 Konoha-Maru, NI-24 Zabuza, NI-63 Iruka, NI-65 Moegi, NI-92 Shino, NI-95 Neji, NI-101 Jiraya, TA-63 Réunion des 9 aspirants, TA-74 Monnaie d’échange, TE-34 Grande Cataracte, Gaara, etc. — **liste non exhaustive**.
- Annonce officielle d’époque : pages **carddass.fr** (tournois) — à récupérer via Wayback.

**Modèle Placarr** : pas un second `printKey` magique — plutôt **même print** + axe exemplaire / variante `promo` + `shurikenCount` (1|2|3), comme finish foil. Checklist complète des promos = chantier (forum + photos + archives).

#### Finitions retail (pas des « autres cartes », mais d’autres tirages)

- **Commune vs Holo** sur le même `NI/TE/TA` (Manga-News le tague carte par carte).
- Holos de starters / boosters ≠ promos shuriken.

#### Vague **Nouvelle Série** (2012)

- Retour FR après pause ; **~118 cartes** ; compatible anciens decks.
- Liée à *Naruto Shippuden: Ultimate Ninja Storm Generations* — **Card Edition** EU (starter + booster + codes in-game).
- Manga-News : [Deck Nouvelle Serie](https://www.manga-news.com/index.php/goodie/Naruto-Deck-Nouvelle-Serie) (sortie ~mars 2012).
- **Hors** Coleka « Carddass Séries Françaises » 01–05 si on s’arrête à 2008 — **à inclure** si le scope = tout le JCC Bandai FR jouable.

#### Produits / trous de numérotation

- Starters thématiques (Maître Hokage, Pays du Vent, Détruire Konoha, Sceller le Maléfice, …) — [SciFi-Universe gamme](https://www.scifi-universe.com/jeux/10095/naruto-jcc/gamme).
- Decks Manga-News listent aussi des **réimpressions** d’anciens numéros dans un deck plus tardif (ex. Série 5 reprend NI-029, NI-191…).
- Trous dans les plages (ex. NI-313 isolé en Série 5) — checklist deck ≠ set booster complet.
- Forum évoque une éventuelle **Série 6** FR jamais claire — à vérifier (probablement non sortie / rumeurs Shippuden).

#### Autres lignes à **ne pas** fusionner dans le même catalogue

| Ligne | Pourquoi hors printKey CACG FR |
|-------|--------------------------------|
| EN Tournament Packs 1–4, tins (*Ultimate Battle*, *Fierce Ambitions*, …), promos **`PR-xxx`** | Autre locale / autre préfixe |
| JP promos **`PR`**, Jump / 非売品, magazine | Autre locale |
| **Data Carddass** (`DN-…`) | Arcade |
| **Miracle Battle Carddass** Naruto | Autre jeu Carddass |
| Panini / Ultra (Vintage Naruto « French ») | Pas Bandai NI/TE/TA |
| Kayou, Mythos, TCG Bandai 2027 | Autres jeux |

## 2. JP — Carddass NARUTOカードゲーム

- Lancement **décembre 2002** (巻ノ壱 : starters + Carddass100 + boosters).
- Extensions « 巻ノ… » jusqu’au moins **巻ノ十六 / 十七** (~2006) ; listes produit hobbyistes + archives [carddass.com/naruto](https://web.archive.org/web/20160304124212/http:/www.carddass.com/naruto/product/).
- Types : 忍 / 術 / 作戦 (+ 依頼人 sur certaines bases).
- Croisements tardifs avec **Data Carddass** (promos `DN` dans boosters) — à **exclure** du printKey Carddass CG sauf intention explicite « Data Carddass ».

## 3. EN — Naruto CCG (Bandai USA)

- Sortie **avril 2006** (*The Path to Hokage*), arrêt **mai 2013** (set 28 *Ultimate Ninja Storm 3*).
- Foils physiques : foil aléatoire + lettering foil sur rares ; Super Rares — **finition exemplaire**, pas de pipeline digital.
- **Hors main sets** : Tournament Packs 1–4 ; tins (*Ultimate Battle*, *Fierce Ambitions*, *Untouchables*, *Rebirth*…) ; promos préfixe **`PR-xxx`** (souvent sans dots de rareté).
- Archives cardlists : [bandaicg.com (Wayback)](https://web.archive.org/web/20081110102739/http:/www.bandaicg.com/naruto/cardlists_s1.html), spoilers Pojo, CCG Trader / Vintage Naruto.

## 4bis. Wayback Machine — sondé 2026-08-12 (CDX)

Pas une piste vague : **les sites officiels sont archivés**, avec des **JPEG de cartes**.

### A. `www.carddass.fr/naruto/` — officiel FR (★ priorité dump)

Hub ~2007–2012, ex. [capture 2007-11-11](https://web.archive.org/web/20071111162612/http://www.carddass.fr/naruto/) :

- Catalogue starters / boosters : `catalogue.htm`, `catalogue_s1.htm` … `catalogue_s4.htm`
- FAQ cartes (refs `NI-…` / `TA-…`), tournois (classiques, régionaux, CdF), « carte de la semaine », deck du mois
- Mentions **série 5** dans les news hub

**Images cartes** sous `…/naruto/images/cartes/` — **~905 JPEG** (+ GIF/PNG) indexés CDX (collapse urlkey). Audit Placarr 2026-08-12 :

| Bucket | ≈ | Placarr |
|--------|--:|---------|
| Faces NI/TE/TA/CL parseables (art+back) | **747** | `data/naruto/ccg/cards/` → **742** printKeys |
| `cartes_med/` miniatures | mappés → **move** `cards/…/thumb.jpg` ; seuls les non mappés restent | `staging/…/cartes_med/` (restes) |
| `cartes/promo/` collages / tin-box (hors faces typées) | faces **NI-PR11/16** → **move** `cards/promo/…` ; reste staging | `staging/…/promo/` + packshots non utilisés |
| Packshots / logos | staging (sauf thumbs tin déjà installés) | `staging/…/packshots/` |
| Chrome site (UI, comment jouer, …) | **62** | `staging/carddass-fr/images/` |

**Verdict dump carddass.fr/images** : **exhaustif pour ce que Wayback a en bytes**
(0 miss sur les 747 faces typées CDX). **Pas** exhaustif pour tout le FR jouable :
l’index Apache S5 listait des JPEG **jamais crawlés** (6 MN S5 + 2 avers absents
avec seulement `-vc`). Détail recovery / pistes :
[naruto_carddass_fr_recovery.md](naruto_carddass_fr_recovery.md). Hors site =
Nouvelle Série 2012, promos shuriken, gap Coleka S2.

**Convention fichier ↔ printKey** (à normaliser au dump) :

- `NINJA-023` → `NI-023` ; `TACTIQUE-190` → `TA-190` ; `TECHNIQUE-030` → `TE-030` ; `CLIENT-018` / `CL-027` → `CL-…`

## 6. Implications Placarr

1. **Pack ombrelle `naruto`** (comme `pokemon` / `lorcana`) — **pas** un pack par ligne produit. Les lignes = **sets préfixés** :
   - Layout : `cards/{sN|promo}/{fr|en|jap}/` → printKey `naruto:s4-ta190` (lang hors clé)
   - Même pack pour les trois locales ; EN/JP encore staging jusqu’à promotion sous `cards/{set}/{en|jap}/`
2. **Catalogue fermé** (CACG FR) : candidat idéal pour une **DB locale terminée** (`data/naruto/…` : `catalog.sqlite` + images) — backlog **« Catalogues locaux finis »**, [data-layout.md](data-layout.md).
3. **Provider** : pas d’API live — index offline (`pnpm naruto:cards`), pas un poll réseau perpétuel.
4. **FR CACG d’abord** (~741 Coleka + promos + 2012) ; autres lignes Naruto TCG = **nouveaux prefixes de set**, pas un second pack.
5. **Finition** = propriété exemplaire (`foil` / holo / `promo`+shuriken) sans rendu.
6. **Prix** = secondaire.
7. **Data Carddass arcade / Mythos / Kayou / 2027** = jeux séparés (autre `game` / pack) — hors ombrelle CACG/CCG legacy si produit vraiment distinct.
