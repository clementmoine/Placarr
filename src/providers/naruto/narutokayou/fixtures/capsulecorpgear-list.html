How to Use the Database

Search for your favorite Naruto character in the Kayou card list database in english. If you’re not already familiar with the list of rarities and boxes you can read the full collector’s guide here. The guide also has more information on the english US release called Heaven Scroll (Smriti Collectible Cards).

You can search by name, box, rarity, or card number. Each result will show you which tier and wave the card was first introduced to the card game. Tap the card to see its full image.

Huge credit to Diana for supplying the initial card data and images.

How Can I Share Each Card or Box?

To share a specific card type the card number into the search. Then click get shareable link This will put a link into your clipboard that you can send to friends or post online.

The same thing can be done if you select a box from the dropdown.

Is Each Card Exclusive to its Set?

No. As long as the kayou card is not a tier-exclusive rarity it can appear in other tiers in the same wave.
